The Reversible Programming Primer is a comprehensive technical guide to
programming concepts and techniques in reversible computing. These posts
make use of diagrams and analogies to help the reader learn the core
logical concepts of reversible computation from the ground up, and building
a foundation for reversible programming from only a few basic primitives.
